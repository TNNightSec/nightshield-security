IONOS publishing:
1. Your domain needs an IONOS Web Hosting package/webspace. A domain-only contract does not provide webspace.
2. Upload all files in this folder to the document root associated with your domain.
3. Keep index.html, styles.css, script.js, contact.php and nightshield-logo.jpg together.
4. The enquiry form sends to both NightShield email addresses. The From address is the NightShield address required by IONOS; visitor email is used as Reply-To.
5. Make sure PHP is enabled for the domain.

If you use IONOS Webspace Explorer, upload the files to the folder used by your domain. If you use SFTP/FileZilla, upload the same files to the domain's document root.
